# 커스토미(Customy) 홈페이지 기획

## 브랜드
- 이름: 커스토미 / Customy (Custom + my, 나에게 꼭 맞춘 놀이와 배움)
- 한 줄 소개: 놀다 보면 자라는, 나만의 게임
- 핵심 가치: 재미가 먼저 · 배움은 자연스럽게 · 화면 안과 밖을 잇는다
- 마스코트: 상자에서 튀어나온 캐릭터 + 머리 위 새싹 (이름 미정) — 새싹 = 성장 = 자람과 연결

## 1단계 범위: 소개만
사전 신청·문의 폼 없음. 서버 없는 정적 사이트.

## 사이트맵
```
/                         홈
/projects/                프로젝트 목록
/projects/wonso-yeonhui/  원소연희 (주기율표 보드게임, 제작 중)
/projects/jaram/          자람 (습관 성장 앱, 개발 중)
/about/                   회사 소개
```

## 홈 구성
1. 히어로: 로고 + "놀다 보면 자라는, 나만의 게임을 만듭니다"
2. 우리가 만드는 것: 앱 / 보드게임 / 교육 게임
3. 지금 만들고 있어요: 원소연희 · 자람 카드
4. 놀이가 성장이 되기까지: 놀이 → 발견 → 습관 → 성장 (화분이 자라는 그림)
5. 누구와 함께하나요: 아이와 부모 / 교실과 선생님 / 스스로 자라고 싶은 누구나
6. 마무리 문구

## 제품 페이지
- 원소연희: 원소연희 상세페이지 이미지에서 잘라낸 그림 + 텍스트 (이야기, 캐릭터, 구성품, 노는 법, 배움, 대상)
- 자람: 습관을 체크하면 화분이 자라는 개념 데모 (실제 앱 화면 아님 명시)
